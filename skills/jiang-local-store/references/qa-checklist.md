# 实体店视觉验收

必须实际查看成图和最终排版。任一红线失败，只重做失败资产或图层。

## 事实红线

- [ ] 菜名、规格、价格、日期、电话、地址、套餐数量和活动条件与来源逐字一致。
- [ ] 没有新增销量、评价、认证、功效、稀缺、最低价、库存和售后承诺。
- [ ] 二维码来自用户真实文件，能够正常识别；没有模型生成的假二维码。
- [ ] 未知原料、辣度、过敏原和份量没有被补写。

## 菜品

- [ ] 菜品类型、份量、块数、餐具、配菜、酱汁和摆盘没有漂移。
- [ ] 已与来源图并排检查颜色、纹理和局部形态；仍像同一道菜但被模型重新绘制，也标记为 `revise-dish`。
- [ ] 没有重复菜品、悬浮食物、不可能的油光、塑料质感或错误生熟状态。
- [ ] 没有真实菜品图时，成品明确标记为概念图，不进入外卖实图状态。

## 食品品牌图与风格

判断与返修细则见 [食品品牌图判断流程](food-art-direction.md)；新F模板默认 `pending-generation`，不继承其他模板的实跑状态。

- [ ] 已实际看每张来源图，记录原图优点、可见身份、用途与允许修改；未知数量、配方、温度不猜。
- [ ] 商品参考与 `style-only` 参考分开，风格图中的食物、餐具、品牌未迁入本次商品。
- [ ] 选中的F风格适配来源视角和光线；品牌色优先，圆弧不是强制默认，多种方案有构图/材质/光线差异。
- [ ] Prompt与实际工具参数中的商品编号、参考图、数量、保护区域和比例一致；可读取二次扩写时已核对，无法读取时未伪称检查过。
- [ ] 输出实际宽高来自解码结果；未把4:5静默改成3:4，未用拉伸或裁掉菜品解决画幅冲突。
- [ ] 在约320px缩略图和100%局部与原图对照：主体清晰、食物色彩可信、材质分明，杯口、反射、阴影和接触关系没有破绽。
- [ ] `strong-brand`任务预定的至少两项获准变化确实出现，原图好的食物颜色与细节没有变差；不以仅加黄、加饱和度或换相近底色冒充明显提升。
- [ ] 同组保留一致品牌语言；有质量参考时实际比较并记录差距，没有参考时不宣布达到某个未知样张的质量。
- [ ] 背景层任务的生成Prompt中没有同时要求绘制菜品；严格身份任务直接用原照片，不用相似重绘图顶替。
- [ ] 风格不达标标记 `revise-style`；记录定向修改与授权重试上限，只重做失败资产，不无限抽卡。
- [ ] 模板/提示词检查、实际生图、视觉验收、用户批准和真实门店验证分别记录；只写Skill或Prompt时没有额外扣费。

## 门头与空间

- [ ] 门窗、墙体、柱体、招牌位置、相邻店面、街道关系和固定设备没有漂移。
- [ ] 已检查整张图，而不只是主招牌；相邻橱窗、包装、设备铭牌、空调和室内画框没有伪文字或品牌样痕迹。
- [ ] 门头只标记为效果预览，不冒充施工图、审批结果或真实完工照片。
- [ ] 没有遮挡出口、跨越租赁边界或不可能施工的结构。

## 菜单、海报与团购

- [ ] 精确文字由 HTML、SVG 或程序层渲染，不是图片模型自由生成。
- [ ] 需要保留真实菜品身份的活动图采用背景层＋原菜品确定性合成，或有逐项对照证明参考图编辑未重绘主体。
- [ ] 观看距离、字号、信息层级和留白适合实际使用位置。
- [ ] 印刷稿记录成品尺寸、出血、安全区、分辨率和颜色要求。
- [ ] 团购套餐的菜品、数量、价格、有效期、不可用日期和使用规则齐全。

## 精准编辑

- [ ] 只有 `Change Set` 指定内容发生变化。
- [ ] `Protected Regions` 中的菜品、Logo、价格、二维码、门窗和版式保持不变。
- [ ] 有修改前后对照；无法可靠保护时已改走确定性合成。

## 网站与多端

- [ ] 桌面端和手机端分别构图，不机械裁切。
- [ ] 页面、网站资产包、已部署和已公开四种状态没有混淆。
- [ ] 地图、电话、地址、表单和营业时间经过人工确认。

## 批量与数据

- [ ] 只规划当轮需要的资产；记录本任务 `runtime_profile` 与 `image_provider`。新教学任务默认 `image2-api`，已选Flova的生产任务保持 `flova-production`，没有改变其他窗口或静默回退。
- [ ] doctor只计配置检查；新图经当轮费用与素材授权实际完成一张小样，完成生成、下载、解码和身份验收后再扩展。
- [ ] 每张资产有 `asset_id`、场景、来源、执行模式、尺寸、版本和状态。
- [ ] A/B 版本只有测试假设；赢家只由后台真实转化数据决定。
- [ ] 上传、印刷、施工和网站发布仍保留人工确认。

## 完整图文笔记

- [ ] C端种草与B端官方品牌/老板身份明确；没有虚构顾客经历，B端没有误写成招商或卖课。
- [ ] 标题、正文、标签、封面和图片顺序齐全；套餐图未展示的商品有明确说明。
- [ ] 新图经本任务选定的Image2/API适配器或Flova执行；已有图直接复用，AI和真实打卡没有混淆。一个profile成功不冒称另一个已跑通。
- [ ] 排版有归藏Social Card真实seed和版本来源，微调范围明确。
- [ ] 实际PNG/JPG存在且可解码；手机阅读、图片加载、文字边界和裁切均已看图检查。
- [ ] 连续更新仍使用同店事实，换内容角度而不制造新活动或顾客体验。
- [ ] 源文件、导出、视觉验收、人工批准和发布状态分别记录。
- [ ] 归藏、浏览器/导出与建站等宿主依赖有实际可访问证据；没有把“包中写了名字”计成已安装。
- [ ] 没有把S01/S06菜单视觉或S12网站资产说成完整外卖运营、完整网站实现或已上线。

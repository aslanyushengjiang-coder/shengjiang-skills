# 包内Image2接口引擎

本Skill直接包含同步Image2与异步APIMart适配器，不要求安装其他Skill。两个脚本放在同一scripts目录；异步脚本复用同步脚本中的输入、解码、下载与错误处理函数。

先读[任务路由](../runtime-routing.md)和[Prompt锁](prompt-system.md)，再按供应商协议选择[同步接口](relay-setup.md)或[异步接口](apimart-setup.md)。不能仅看服务名称判断协议，也不能静默更换供应商。

## 本地能力与真实服务

- generate/edit参数检查、Prompt摘要、PNG数据验证、同步请求构造、异步提交/轮询/下载已经由脚本实现。
- dry-run在本地构造请求摘要，不发送HTTP、不需要Key、不产生模型图。
- doctor默认只检查配置；模型列表可见也不能证明模型真实身份或生图成功。
- 请求参数中的gpt-image-2只是可配置模型名，服务是否支持、如何计费、保留何种数据，必须按实际供应商核对。
- APIMart CLI没有resume/status子命令。提交状态不明时保留task_id，先核对原任务，不能自动重发。
- JPEG/WebP解码需要已有Pillow；PNG校验使用标准库。脚本不自动安装软件。

## 接口安全

真实凭据只走可信 HTTPS；鉴权 API 的所有自动跳转均拒绝，必须直接配置最终端点。返回图片使用独立、无鉴权的 HTTPS 下载请求。

## 真实生成门禁

先确认费用、模型/接口、参考图权利与数据上传范围；再做一张授权小样，下载并实际解码，逐项比较菜品、份量、摆盘、餐具与精确文字。不能用其他工具生成的图片替代本接口测试。任何阶段失败都写明实际状态。

用图片模型生成无字视觉，用确定性SVG/HTML写价格、日期、地址、规则等事实。严格保留菜品像素时只生成背景，再放入原菜品照片。示例图片仅供本地测试，不能当作真实门店商品。

## 可重跑测试

[适配器测试](../../tests/test_image_adapters.py)只使用本机loopback TLS、临时测试证书和fake Key，不连接真实供应商。测试运行还需本机openssl；没有时如实报告测试依赖，不自动安装。测试结果只代表本地协议与错误处理，不代表真实模型、费用、成图质量或WorkBuddy安装。

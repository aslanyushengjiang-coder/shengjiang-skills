# 宿主能力检查

先调用 `scripts/doctor.py`。它仅报告Python版本、包是否可导入、可能的浏览器路径；
发现可执行文件不是浏览器启动成功，更不是WorkBuddy工具已获授权。
随后在宿主中分别确认读取用户授权文件、执行命令、联网搜索、浏览器读写、PDF渲染是否可用。
每项记录 `available / unavailable / not_tested` 和实际证据。

基础数据工具不联网。`jobctl.py jobs import` 导入已有文件；`jobs screen` 做全量字段初筛。
网页搜索、读取JD、逐句事实判断、模拟追问由宿主Agent完成；不要伪称CLI自动完成这些智能任务。
安装Skill不会自动赋予电脑控制、验证码处理、邮箱读取或后台运行权限。

搜索不可用：输出检索式和待核实表，不能写“官网已确认”。浏览器不可用：输出字段映射和人工待填清单。
命令不可用：先提供Markdown/CSV文本，不宣称SQLite已保存。PDF不可用：交付可编辑HTML/纯文本，标注未完成。
图片型简历先尝试宿主视觉能力；解析不全时让用户确认关键事实，不猜测文字。

本包只读检查不执行安装。安装Python包、浏览器、连接器或扩展前说明来源和用途并获得授权。
不强制关闭沙箱，不关闭用户标签页，不开放调试端口到公网。定时和提醒单独确认，不作为首次使用前提。

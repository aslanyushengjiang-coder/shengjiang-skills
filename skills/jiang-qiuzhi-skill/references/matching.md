# 资格检查、匹配证据与排序

资格为三态：pass / fail / unknown。先比较招聘类型、毕业时间窗、明确专业学历、资格证书、
截止时间与用户明确硬限制；fail不靠高分抵消，unknown必须先补证据。
脚本初筛只覆盖部分标准化字段，不负责理解所有JD硬要求。

完整JD诊断逐项列：招聘要求原文、必需/优先、用户对应事实ID、同经历直接证据/可解释迁移/无证据、
表达缺口/信息缺口/能力缺口、建议动作。

需要评分时采用同一套内部量表：校招技能30、项目实习25、学历届别专业20、证书语言10、意向15。
社招另用职级要求30、相关成果30、技能20、业务域10、意向10。
必需项权重2、优先项1；直接证据1、可解释迁移0.5、无证据0。
只在完整JD已读且资格不为fail时报告分数；unknown需醒目标注未完成资格核对。
JD没有要求的维度注明不适用，分母相应调整并显示具体计算，不为凑100分捏造要求。

匹配分与表达清晰度分开报告。重写措辞、排序或排版不会改变事实能力分。
新增真实事实才重评，并逐条说明对应证据。不同JD的分数不能拿来证明同一简历变强。
该量表不是招聘方实际打分、ATS测试、录取概率、实际效果或承诺。

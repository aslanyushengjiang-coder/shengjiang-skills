# 自动测试和真人验收

先运行：`python -m unittest discover -s <SKILL_DIR>/tests -v`。
自动测试使用临时目录与虚构数据，不登陆网站，不写真实投递。
自动测试覆盖本地规则，不覆盖Agent对自然语言的全部理解，更不能代替浏览器站点测试。

真人在WorkBuddy逐项验证：
- 技能导入成功与触发；非仅在文件中看到了名称。
- 读取一份无隐私简历，已有信息不重复问。
- 官网检索真实岗位，查看完整JD、资格、日期、链接并留证据。
- 导入真实秋招表，对照各sheet原始行数及所有异常；抽样核对初筛原因。
- 一份真实经用户确认的简历：逐句事实核对、A4、页数、可提取文字、所有页视觉检查。
- 两个方向、两个岗位，不错配版本；上传前哈希与文件名核对。
- 本地demo表单填写与回读，保持未提交；随后在用户许可下测试具体真实ATS。
- 登录、验证码、未知字段、声明和最终提交能够正确停止。
- 草稿不计正式投递，真实通知正确记录，不把模拟变成已进面。
- 完成一次6题练习与真实复盘的下一轮读取，不预设事件，不保存逐字回答。
- 安装目录无用户数据和凭据，不把本地待办描述为已开启通知。

任何待测项必须保持待测，不把旧版实机结果算作新版已跑通。

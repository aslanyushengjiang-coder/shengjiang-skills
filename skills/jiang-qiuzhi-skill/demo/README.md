# 虚构演示资料

本目录所有人物、学校、经历和岗位均为虚构，网址使用example.invalid，不提供真实投递入口。
用于录屏排练、字段导入和功能测试，不能作为真实求职数据或就业成果。

profile.json：演示画像与已确认的虚构事实库。
resume-before.txt：原始演示简历；resume-after.json：同事实的结构化整理。
jobs-fictional.csv：用于重复、届别、城市、截止与待确认的多种测试。
application-form.html：离线表单，提交按钮被禁用，不发送任何数据、不写localStorage。

只在新的测试工作区运行。切回真实求职时另建工作区，不把演示记录混进正式数据。

工作簿 `jobs-fictional.xlsx` 分为岗位A/B两表，合计13行；预览输出位于 `outputs/`，全为虚构且不可投递。

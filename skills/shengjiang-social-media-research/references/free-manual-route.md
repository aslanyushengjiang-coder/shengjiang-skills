# 社媒助手免费手动路线

## 适合谁

适合没有 API Key、希望先免费试用、样本量不大，或第一次做社媒调研的小白。

“免费手动”表示：用户在浏览器中自己安装、登录、点击采集和导出；AI 提供操作引导，并处理导出的 Excel。它不是后台全自动抓取。

官方入口：

- 下载：https://socialext.com/download
- 版本与功能：https://socialext.com/pricing
- 使用帮助：https://socialext.com/help
- 飞书同步教程：https://socialext.com/help/guide/feishu

官方当前下载页列出的支持平台包括小红书、抖音、B站、快手和 TikTok。支持范围、免费额度和字段可能变化，以官方页面为准。

## 小白操作步骤

### 1. 安装扩展

1. 打开官方下载页；
2. 优先选择 Chrome 扩展商店安装；
3. 如果商店无法访问，严格按照官方页面的离线安装说明操作；
4. 点击浏览器右上角“拼图”图标，把社媒助手固定到工具栏。

只从官方页面下载，不使用来源不明的安装包。

### 2. 打开目标页面

1. 在浏览器登录目标平台；
2. 打开关键词搜索结果页、博主主页、作品列表或评论页；
3. 确认页面上能看到你要采集的内容；
4. 首次只选 3–10 条验证字段。

登录、验证码和账号权限由用户自己完成，AI 不索取 Cookie 或密码。

### 3. 选择采集内容

在扩展面板里选择当前页面支持的采集类型，例如：

- 博主基本信息；
- 作品列表和互动数据；
- 当前作品详情；
- 评论；
- 搜索结果。

不同平台和版本显示的按钮可能不同。看不到某项时，先查看官方帮助，不凭空假设扩展支持。

### 4. 导出 Excel

1. 检查采集数量和字段；
2. 点击导出 Excel；
3. 文件名建议包含平台、对象和日期，例如：

```text
xiaohongshu_AI实操_2026-07-28.xlsx
```

4. 保留原始 Excel，不要直接在原文件上删除列或覆盖内容。

免费版通常提供基础采集和 Excel 导出，但具体次数、批量上限和高级功能以当前官方价格页为准。

### 5. 交给 AI

把 Excel 文件交给 AI，并使用类似指令：

```text
调用 shengjiang-social-media-research 处理这份社媒助手导出的 Excel。
先检查字段和数据量，保留原始文件；然后去重、统一数字和时间格式，
生成账号表、作品表、评论问题聚类和 20 个可执行选题。
所有结论都要能回指原始链接。
```

如果需要同步飞书，先读官方飞书教程。App ID、App Secret 等凭证只在用户自己的安全环境里配置，不发到聊天或公开文档。

## 常见问题

- 导出为空：确认页面已经加载、登录状态正常，并先采当前可见的小样本；
- 评论不全：平台可能要求展开评论或限制可见数量，按官方帮助操作；
- 字段缺失：保留现有字段，在结果中标注缺口；
- 数据重复：按平台内容 ID 或标准化链接去重；
- 平台不支持：改用平台创作者后台导出、用户提供链接清单，或选择合规的第三方 API。

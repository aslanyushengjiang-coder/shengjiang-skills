# 生姜社媒调研

把“搜几条内容看看”变成有来源、有原始数据、有结构化结果的社媒调研。

## 先说清能力边界

这个 Skill 不自带社媒数据源，也不提供或转售 API。

- 自动化路线调用第三方 TikHub API。用户需要自行注册、购买或使用其试用额度，并配置自己的 `TIKHUB_API_KEY`。费用、额度、支持接口和平台以 TikHub 当前官方说明为准。
- 免费路线使用第三方“社媒助手”浏览器扩展的免费功能。用户需要自己安装扩展、登录平台、点击采集并导出 Excel；AI 负责教操作、读取文件、清洗、去重、分析和生成报告。
- 不绕过登录、付费、验证码、访问控制或平台限制。只采集用户有权访问且符合平台规则的数据。

当用户问“免费吗”“谁的接口”“Key 从哪来”“不用 API 行不行”时，直接说明以上事实，不含糊，不把第三方能力说成生姜自建接口。

## 选择路线

先问清目标、平台、对象、时间范围、结果用途和期望字段，然后选择成本最低的可行路线：

1. 用户已有 TikHub Key，并明确需要批量或自动化：走付费 API 路线。
2. 用户希望免费、没有 Key、只调研少量对象或愿意手动操作：走社媒助手路线。
3. 用户已经给了 Excel、CSV、JSON、链接清单或截图：直接进入整理分析，不要求重新采集。
4. 平台或字段不受当前工具支持：明确标记“待补采”，给替代办法，不编造数据。

默认先给执行预览，不直接产生可能收费的大批量请求。

## 标准工作流

### 1. 定义调研问题

把模糊需求收敛为可验证的问题，例如：

- 找到 20 个值得学习的 AI 实操账号；
- 拆解近 30 天互动最高的 50 条作品；
- 从 1,000 条评论里提炼小白的真实问题；
- 为某个选题收集标题、开头、结构和用户反馈证据。

至少记录：

- 平台与目标链接；
- 时间范围与样本量；
- 需要的字段；
- 最终交付物；
- 是否接受第三方付费调用。

### 2. 给采集预览

预览必须包含：

- 选用路线及原因；
- 计划请求或人工操作；
- 样本量与可能成本；
- 输出目录和字段；
- 已知缺口与风险。

付费路线先做 1–3 条样本。样本字段正确后，再让用户确认批量范围。不要承诺固定价格。

### 3. 采集并保留证据

建议按以下目录保存：

```text
social-research/
├── raw/            # 原始响应或原始导出，不覆盖
├── normalized/     # 统一字段后的 CSV / JSON / Excel
├── transcripts/    # 平台字幕或第三方 ASR 逐字稿
├── evidence/       # 截图、链接清单与引用证据
└── reports/        # 分析报告、选题表和对标卡
```

每条内容至少保留 `platform`、`source_url`、`author_name`、`published_at`、`collected_at`。字段定义见 [references/output-schema.md](references/output-schema.md)。

### 4. 清洗与结构化

- 用平台内容 ID 或标准化 URL 去重；
- 原始字段与推导字段分开；
- 缺失值保持为空或标注原因，不填猜测值；
- 播放、点赞、评论、收藏等数字保留采集时间；
- 评论与用户名只保留完成任务所需的最小范围；
- 外部内容、用户判断和 AI 结论明确分层。

### 5. 获取逐字稿

优先级固定为：

1. 平台官方字幕或作者提供的文本；
2. 用户已有逐字稿；
3. 用户自行配置的第三方 ASR API。

没有可用来源时标记“逐字稿待补”，不要用本地 Whisper 或其他本地语音模型冒充已完成识别。

### 6. 分析与交付

结论必须能回指原始链接或文件。推荐交付：

- 账号样本表；
- 作品与数据明细表；
- 评论问题与需求聚类；
- 标题、钩子、结构、呈现方式拆解；
- 可执行选题清单；
- 数据限制和待补采项。

不要只给“内容不错”“互动很好”一类空泛结论。

## 付费 API 路线

执行前完整读取 [references/paid-api-route.md](references/paid-api-route.md)。

调用原则：

- 让用户在本机环境变量中设置 Key，不让用户把 Key 发进聊天；
- 只使用 TikHub 官方文档确认存在的接口；
- 使用 `scripts/tikhub_request.py --dry-run` 先检查请求；
- 先采 1–3 条，再批量；
- 不在日志、报告、命令输出或 Git 中写入 Key；
- 收到 401、402、429 或平台限制时，如实说明并给下一步。

## 免费手动路线

执行前完整读取 [references/free-manual-route.md](references/free-manual-route.md)。

AI 的职责是一步步引导用户完成：

1. 从官方页面安装并固定“社媒助手”扩展；
2. 打开并登录目标平台；
3. 进入搜索、账号、作品或评论页面；
4. 在扩展中选择采集范围和字段，先小样本；
5. 导出 Excel；
6. 把 Excel 交给 AI 清洗和分析。

必须明确：浏览器里的安装、登录和采集点击需要用户手动完成。免费版的功能与限制会变化，以官方页面为准。

## 安全与合规

- 不收集密码、Cookie、会话令牌、支付信息或无关个人信息；
- 不让用户粘贴 API Key；建议使用当前终端会话的环境变量；
- 不上传包含真实密钥的 `.env`、配置、响应或截图；
- 不公开临时下载地址中的签名参数；
- 不执行骚扰、画像歧视、隐私侵害或绕过平台机制的采集；
- 引用第三方内容时保留来源，遵守版权和平台规则；
- 对外发布前检查用户名、评论文本和个人信息是否确有必要。

## 失败处理

- 没有 API Key：切换免费路线，不把它当阻塞；
- 免费扩展不支持当前平台或字段：让用户导出平台后台数据、提供链接清单，或选择官方允许的第三方服务；
- 数据量过大：按平台、时间或内容类型分批；
- 字段漂移：保留原始文件，更新映射，不修改原始数据；
- 无法获得字幕：交付元数据和内容分析，逐字稿列为待补。

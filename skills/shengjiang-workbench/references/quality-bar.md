# 工作台质量门槛

## P0：必须通过

- `index.html` 能打开；
- 页面能加载配置；
- 首版模块与确认单一致；
- 新增、删除、完成或状态修改至少有一种真实交互；
- 刷新页面后数据仍在；
- 支持导出和导入 JSON；
- 不在前端文件中保存 API Key、Token、Cookie 或密码。

## P1：交付前应通过

- 手机宽度下没有横向溢出；
- 菜单名和按钮名使用用户能理解的语言；
- 首页能看见当前最重要的信息；
- 空状态告诉用户下一步做什么；
- 删除和清空数据有确认；
- 使用说明写清数据保存位置和备份方法；
- 模块 ID 稳定且唯一。

## P2：可在后续迭代

- 主题切换；
- 更丰富的数据图表；
- 键盘快捷键；
- 云同步；
- 登录与权限；
- 多人协作；
- 真实 AI 助手；
- 自动化和通知。

## 交付说明

必须分别标记：

- 已完成；
- 已结构检查；
- 已浏览器交互验证；
- 暂未包含；
- 需要第三方服务。

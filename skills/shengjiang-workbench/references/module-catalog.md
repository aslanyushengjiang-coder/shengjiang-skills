# 模块目录

模块目录只用于启发，不是必装清单。

| 模块 | 适用场景 | 推荐类型 |

| 日历 | 预约、截止日、本周节奏 | `calendar` |
| 收集箱 | 临时想法、链接、待整理资料 | `inbox` |
| 习惯 | 每日习惯、打卡状态 | `habits` |
| 项目 | 项目目标、下一步、进展 | `projects` |
| 记录与复盘 | 日记、心情、经验、周复盘 | `journal` |
| 知识与资料 | 笔记、事实源、资料索引 | `knowledge` |
| 内容生产 | 选题、草稿、审核、发布 | `content` |
| 会议 | 会议记录、决议、行动项 | `meetings` |
| 数据复盘 | 指标、观察、结论 | `metrics` |
| 健康 | 睡眠、运动、心情、用药等个人记录 | `health` |
| 预算与账单 | 收支、预算、订阅和账单提醒 | `finance` |
| 家庭生活 | 买菜、餐食、家务、家庭联系人 | `home` |
| 客户与线索 | 联系人、阶段、下一步 | `projects` |

## 普通人日常模式

公开的日常计划与 Personal OS 产品里，反复出现的不是复杂行业模块，而是下面这条闭环：

```text
随手收集 → 本人确认 → 日历/今日行动 → 完成或调整 → 记录与复盘
```

默认首版使用“日常六件套”：

- **今日**：只看现在真正要推进的下一步；
- **日历**：预约、截止日和本周节奏；
- **收集箱**：先接住想法、截图、链接和提醒，不自动把所有输入都变成任务；
- **习惯**：记录今天是否完成，避免用连续天数制造压力；
- **目标与项目**：把长期目标连接到本周下一步；
- **记录与复盘**：保留事件、感受、调整和经验。

全局搜索、AI 助手、设置与数据属于系统能力，不重复占用模块名额。“今日”应汇总日程、习惯和待确认内容，不为同一件事制造副本。

以下内容按需要启用，不默认塞满首页：

- 健康包：睡眠、运动、心情、用药；
- 财务包：预算、收支、账单、订阅；
- 家庭包：买菜、餐食、家务、联系人、家庭文档；
- 学习与媒体包：阅读、课程、书影音、书签。

涉及健康、财务、家庭成员或证件的资料属于敏感信息。首版优先本地保存，并明确备份、导出和访问边界。

## 自媒体建议

首版通常从以下模块选 4–7 个：

- 今日；
- 收集箱；
- 选题池；
- 对标调研；
- 脚本与内容；
- 发布排期；
- 数据复盘。

不要把选题、草稿、定稿拆成多个互不关联的副本。优先使用一个内容模块中的状态流转。

## 学习建议

视频同款学习工作台底座：

- 今日；
- 单词本；
- 每日阅读；
- 错题本；
- 习题练习；
- 听力口语；
- 语法笔记；
- 收集箱；
- 全局搜索；
- AI 助手；
- 设置与数据。

其中搜索、AI 助手和设置属于系统能力，不要求用户在需求表里重复填写。

## 自定义模块

如果目录中没有合适类型，使用 `custom`。自定义模块仍需明确字段、输入、动作和输出，不要只写一个空标题。

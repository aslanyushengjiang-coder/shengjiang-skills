# 产品库：能卖什么，怎样交付

管理可销售、可交付的产品事实，以及产品从研发到交付改进的证据。先读本说明与本库 `_资料索引.md`，按任务读取相关原件。

## 建议子库

下表是文旅业务分类方案。根据机构实际角色和已有资料启用：有材料或明确任务时才创建对应目录；没有材料先在索引记“待补”，业务不涉及则记“不适用”。目录未创建时不要生成指向它的链接。已有成熟目录保持原名，索引登记映射即可。

| 建议子库 | 放什么 | 归属边界与使用条件 |
| --- | --- | --- |
| 01.市场需求与产品规划 | 目的地及季节需求、公开竞品、客群需求汇总、产品定位、年度产品规划与在售目录 | 外部观察标明来源和日期；本机构客户原话留客户库，产品库引用脱敏结论；规划不等于已上线 |
| 02.目的地与供应资源 | 酒店、景区、营地、交通、餐饮、师资、地接供应商档案，考察记录、资质、合作条款和履约评价 | 供应商是提供资源的一方；卖产品的渠道伙伴归客户库。同一机构兼任两种角色时关联原档案，角色与条款分别注明 |
| 03.线路活动与课程 | 周末活动、亲子线路、营期、学校研学、团建、地接接待产品；行程、学习目标、教案、研学手册、活动玩法 | 某产品的具体教案和手册留这里；通用教学方法及编写步骤归技能库。记录适龄、时长、强度、服务标准与限制 |
| 04.成本价格与交易规则 | 供应成本、计价单位、成本核算、零售/同业价格、儿童价、房差、优惠、费用包含与不含、退改规则 | 区分内部成本和对外价格；绑定适用日期、人数、团期、渠道和批准依据；特定客户的报价与成交约定归客户库 |
| 05.团期与项目交付 | 某次实际团期或学校项目的事实卡、资源预订、容量、排期、工作人员、执行表、现场记录、项目成本与供应结算 | 一场实际交付一个主档案，关联所用产品版本和订单；名单、个人健康信息、个人收退款留客户库受控原位置。项目主档只保留必要引用 |
| 06.品牌资质与销售资料 | 公司介绍、品牌规范、机构资质、师资介绍、已获证据支持的案例、招商推介、产品问答、标准介绍 | 宣传承诺、资质有效期与案例使用授权可追溯；投标通用资质留这里，某客户的投标应答文件归该商机 |
| 07.内容素材与历史成品 | 照片、视频、产品地图、海报、公众号、朋友圈、短视频、招募页、小程序素材及其实际发布记录 | 按产品和用途关联；记录真实/生成、肖像使用范围、使用渠道、草稿/已采用/已发布，过期团期素材不能直接复用；通用制作方法归技能库 |
| 08.产品反馈与迭代 | 产品体验问题、供应履约评价、团期复盘、成本偏差、课程效果、产品改版及验证结果 | 客户原始投诉留客户库；这里聚合脱敏的产品问题。改进建议、已批准改动、已执行结果分别记录 |

## 机构类型如何使用

- 组团社、亲子游品牌：重点是产品组合、采购成本、招募素材、团期交付和复购反馈。
- 地接社、目的地服务商：重点是本地资源、接待能力、同业报价、资源确认和供应结算。
- 学校研学服务商：重点是年级需求、课程目标、师资与资质、学校项目、验收材料。
- 营地、基地：重点是场地容量、设施、课程、导师、接待时段、维护和应急条件。
- 机构可以兼任多种角色；只有本机构确实开展的业务才标为已启用。

## 最少要能找到的事实

沿用现有产品、资源和团期编号；没有编号时使用稳定且不重名的名称/日期组合。无需为了建库重编所有资料。

| 对象 | 按任务需要核对的字段 |
| --- | --- |
| 产品 | 对象标识、目标人群/年龄、地点、行程或课程、时长、服务标准、限制、状态、负责人、事实来源及有效日期 |
| 资源 | 供应方、服务能力、容量、确认状态、适用日期、价格依据、限制、履约评价与原件位置 |
| 团期 / 项目 | 对象标识、产品版本、日期、集合点、容量与报名事实来源、预订确认、执行负责人、订单关联、当前状态、现场记录及交付结果 |
| 素材 | 关联产品/团期、原文件、内容用途、真实性、使用授权、采用状态与发布证据 |

实时库存、报名人数和供应价格如以业务系统为准，索引指向该系统并注明查询时间；本地旧快照不能冒充实时确认。

## 常见调用

做推广先找具体产品与团期事实，再找品牌和可用素材；输出挂回同一个产品或团期，保留草稿状态。做报价先读客户需求，再读资源与成本、适用规则，分别保存对外报价和内部核算。做执行计划先查团期主档，关联客户库的已确认名单和特殊服务需求，再读取技能库对应流程。

价格、日期、资源或服务标准变化时，更新已授权维护的业务主档，保留原始报价、合同和沟通证据；真源在外部系统时通过其授权入口维护。列出受影响的报价、海报、公众号和通知，逐项标记待更新、已修改、已核验。尚未修改的成品不能写成已经同步。

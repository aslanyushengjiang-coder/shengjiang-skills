## 三个业务库

| 入口 | 用途 |
| --- | --- |
| [产品库](01.产品库/_资料索引.md) | 线路、酒店、景点、报价、公众号内容和活动资料 |
| [客户库](02.客户库/_资料索引.md) | 客户名单、档案、已导出的聊天、报名与跟进 |
| [技能库](03.技能库/_资料索引.md) | 团队 SOP、清单和通用模板 |
| [三库交付清单](system/三库交付清单.md) | 接入情况、未处理项、缺失资料和检索验收 |

三库按业务用途分类，system 只维护协作和检查。通用报价归产品，某客户的报价归客户，报价操作步骤归技能。同一原件一个主归属，其他用途用链接关联。未分类资料保留原位置，在交付清单登记。

## 新增内容

写入前先查三库索引，确定所属库和唯一目标路径。原件保持位置和内容；索引回指原文件，提炼内容须标明来源和状态。新建业务文件留在所属库；根目录只保留入口。业务子目录仅在确有材料时创建。

## 版本与冲突规则

1. 导航只负责指路，回答问题仍需读取原始文件。
2. 同一事实存在多个版本时，优先读取目录 README 或局部索引中的状态说明。
3. 没有明确规则时保留冲突并询问，不根据文件名或修改时间自行宣布最新版。

## 默认排除

- 密钥、Cookie、密码、浏览器数据和聊天数据库。
- `.git/`、依赖、缓存和构建产物。
- 明确归档且与当前任务无关的历史文件。

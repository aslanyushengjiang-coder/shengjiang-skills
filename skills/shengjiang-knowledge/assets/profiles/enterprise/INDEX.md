## 三个业务库

| 入口 | 用途 |
| --- | --- |
| [产品库](01.产品库/00-使用说明.md) · [资料索引](01.产品库/_资料索引.md) | 市场与产品规划、供应资源、线路课程、成本价格、团期交付、品牌资料、内容素材、产品迭代 |
| [客户库](02.客户库/00-使用说明.md) · [资料索引](02.客户库/_资料索引.md) | 家庭、学校团体、同业渠道、商机沟通、订单收退款、出行服务、售后转介绍、客群运营 |
| [技能库](03.技能库/00-使用说明.md) · [资料索引](03.技能库/_资料索引.md) | 研发采购、内容获客、咨询报价、计调准备、现场安全、教学评价、售后复盘、岗位与工具 |

三库按业务用途分类，system 只维护协作和检查。通用报价归产品，某客户的报价归客户，报价操作步骤归技能。同一原件一个主归属，其他用途用链接关联。未分类资料保留原位置，在交付清单登记。

## 按任务读取与保存

先在相关库的使用说明和资料索引定位具体对象，再读必要原件和流程，不加载整库。实际执行前按 `system/PROCEDURES.md` 核验事实、权限与输出条件。

| 要做什么 | 读取哪些事实和方法 | 结果保存到哪里 | 关键检查 |
| --- | --- | --- | --- |
| 开发线路或课程 | 产品库需求、资源、既往反馈；技能库研发方法 | 产品研发档案 | 适龄、目标、资源可用、成本、服务限制 |
| 学校/家庭定制方案与报价 | 客户库本次需求；产品库行程、成本、有效价格；技能库方案报价流程 | 客户商机，采用后关联订单与团期 | 需求覆盖、计算、人数日期、费用包含与不含；内部核算与对外报价分开 |
| 海报、公众号或招募内容 | 产品库本期产品/团期、品牌、授权素材；技能库内容制作流程 | 对应产品或团期内容档案 | 价格日期、服务承诺、素材授权、草稿/采用/发布状态 |
| 客户跟进或复购推荐 | 客户库需求、订单历史、下一步与触达范围；产品库可售产品；技能库销售流程 | 客户或商机记录 | 原话与判断分开，不能虚构跟进状态；外发须有授权 |
| 分车分房与行前准备 | 客户库已确认名单和必要服务信息；产品库本次团期已确认资源；技能库计调流程 | 团期执行档案，敏感名单仍留受控位置 | 人数守恒、容量、资源确认、冲突及负责人 |
| 学校投标 | 客户库招标要求；产品库资质、课程、案例与资源；技能库投标流程 | 本次客户商机 | 逐项响应，不能虚构资质、案例或签署承诺 |
| 投诉与退款 | 客户库订单约定和投诉原文；产品库现场记录；技能库售后流程 | 客户订单/售后记录，关联产品问题 | 实际承诺、处理权限、金额、执行证据 |
| 团期或经营复盘 | 产品库团期成本与现场记录；客户库交易与反馈；技能库复盘方法 | 原团期，确认的产品改动和方法分别回原文件 | 统计范围、收入成本口径、实际执行与建议分开 |

跨库通过现有产品、团期、客户和订单标识关联。业务系统已管理的财务、库存、报名或 CRM 记录只登记真源入口及核验时间，不另造一套互相冲突的账本。

## 新增内容

写入前先查三库索引，确定所属库和唯一目标路径。原件保持位置和内容；索引回指原文件，提炼内容须标明来源和状态。新建业务文件留在所属库；根目录只保留入口。业务子目录仅在确有材料时创建。

## 版本与冲突规则

1. 导航只负责指路，回答问题仍需读取原始文件。
2. 同一事实存在多个版本时，优先读取目录 README 或局部索引中的状态说明。
3. 没有明确规则时保留冲突并询问，不根据文件名或修改时间自行宣布最新版。

## 默认排除

- 密钥、Cookie、密码、浏览器数据和聊天数据库。
- `.git/`、依赖、缓存和构建产物。
- 明确归档且与当前任务无关的历史文件。

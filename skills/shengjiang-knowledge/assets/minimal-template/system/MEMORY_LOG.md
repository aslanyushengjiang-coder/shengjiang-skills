# 用户纠正记录

> 用户纠正 AI 时立刻追加，只增不改。每条标注“该类纠正第 N 次”；同类纠正达到 3 次，主动提议升级为 `PROCEDURES.md` 的固定规则。重要任务开始前先翻最近纠正。

## 记录格式

```markdown
## [YYYY-MM-DD] 纠正 | 标题

- 场景：
- 用户纠正：
- 后续行动：（该类纠正第 N 次；满 3 次时在此提议升级为固定规则）
```

## 判断“同类”的标准

看错误模式是否相同，不看字面是否相同。例如“报告腔开场”“总结腔结尾”“列表堆砌”都可以归为“输出不像人话”。

## 边界

- 不记录密钥、隐私和敏感内容，只记错误模式和正确做法。
- 升级为固定规则必须让用户确认。
- 记录只增不改；确认记错的条目由用户决定删除。
